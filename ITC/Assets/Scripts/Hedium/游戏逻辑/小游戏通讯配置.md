# Markdown

1. 创建了 6 个 SequencerCommand 文件
在 Assets/Scripts/唐今脚本/Dialogue/Sequences/ 目录下创建了以下文件：
SequencerCommandStartRuneInputGame.cs - 启动符文输入小游戏
SequencerCommandStartStampGame.cs - 启动盖章小游戏
SequencerCommandStartDocumentVerifierGame.cs - 启动文书核验小游戏
SequencerCommandStartSoulHarvestGame.cs - 启动灵魂收取小游戏
SequencerCommandStartSpecialEventGame.cs - 启动特殊事件小游戏
SequencerCommandStartDebugGame.cs - 启动调试小游戏

2. 在小游戏结束出口添加了 Sequencer.Message() 调用
在 SigningFlowManager.cs 中为每个小游戏添加了完成消息：
符文输入游戏 (RuneInputManager): 在 ToEnd() 方法中发送 "RuneInputGameDone" 消息
文书核验 (DocumentVerifier): 在 ToExit() 方法中发送 "DocumentVerifierGameDone" 消息
盖章游戏 (StampSystem): 在 OnHandCharginSth() 方法中发送 "StampGameDone" 消息
特殊事件 (SpecialEventSystem): 在所有完成/失败路径中发送 "SpecialEventGameDone" 消息
灵魂收取 (SoulHarvestSystem): 在成功/失败路径中发送 "SoulHarvestGameDone" 消息

3. 添加了必要的命名空间
在 SigningFlowManager.cs 文件顶部添加了 using PixelCrushers.DialogueSystem;
使用方法
在对话系统中启动小游戏：
StartRuneInputGame()WaitForMessage(RuneInputGameDone)
各小游戏对应的消息名称：
符文输入: RuneInputGameDone
盖章游戏: StampGameDone
文书核验: DocumentVerifierGameDone
灵魂收取: SoulHarvestGameDone
特殊事件: SpecialEventGameDone
调试游戏: DebugGameDone（如果实现）

所有小游戏在完成时（无论成功或失败）都会向 Sequencer 发送对应的完成消息，对话系统可以使用 WaitForMessage() 等待小游戏完成后再继续对话流程。
