# agents.md

The role of this file is to describe common mistakes and confusion points that agents might encounter as they work in this project. If you ever encounter something in the project that surprises you, please alert the developer working with you and indicate that this is the case in the AgentMD file to help prevent future agents from having the same issue.

- Surprise noted on 2026-04-06: the pause-menu save/load preview hover chain can be partially lost after migration. In `Main Scene`, save/load slot buttons may still have `Button`/`UIBehaviourProxy` or related UI structure, but the actual hover callbacks to `UISolariBoard` are no longer wired, and serialized preview event data in the old slot prefabs can also be incomplete/corrupted. When debugging save/load UI previews, inspect the runtime hover bridge first instead of assuming the board or textures are broken.
- Surprise noted on 2026-04-07: `PauseMenuRouteRuntimeFix` had a load-menu fallback that bound `加载菜单Canvas/存档菜单面板/背景板/提示图翻牌器-加载菜单` to the legacy `Button right` tween when no `LOAD字符`/`SAVE字符` title object existed. In edit mode the preview board looks correctly authored, but once the game enters play and the load panel is shown, that runtime tween shifts the board into the load body and makes hover previews look occluded. If the load preview board only breaks in play mode, inspect runtime legacy tween bindings before changing the board art or slot hover code.
- Surprise noted on 2026-04-07: the checked-in Pixel Crushers Dialogue System is version `2.2.48` according to `Assets/Plugins/Pixel Crushers/Dialogue System/_README.txt`, but current official web docs and forum posts may describe newer 2.2.5x behavior. When applying "official recommended" Dialogue System guidance in this repo, verify it against the local plugin sources under `Assets/Plugins/Pixel Crushers` before assuming inspector options, helper APIs, or runtime behavior match exactly.
- Surprise noted on 2026-04-07: the local Dialogue System plugin has since been upgraded and `Assets/Plugins/Pixel Crushers/Dialogue System/_README.txt` now reports version `2.2.68`, so the earlier `2.2.48` note is stale history rather than the current state. Before answering implementation questions or comparing against vendor docs/forum advice, re-check the local plugin version and source tree instead of assuming older agent notes still match the checked-in package.
- Surprise noted on 2026-04-07: many `Assets/Plugins/Pixel Crushers/Dialogue System/Scripts` C# files are stored as UTF-8 with BOM, and Git may show them as binary-like unless you force text diff (`git diff --text`). Bulk external rewrites can silently strip the BOM and create misleading first-line diffs even when only attribute strings changed. When mass-editing this plugin, explicitly preserve BOM and verify the diff with `--text` if needed.
